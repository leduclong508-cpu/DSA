# 💻 Nhật ký Giải thuật & Cấu trúc dữ liệu (DSA)

Kho lưu trữ này là nơi tôi ghi chép lại hành trình rèn luyện tư duy logic, học hỏi DSA.

## 📂 Cấu trúc dự án

    *   📁 **`BTVN/`**: Bài tập theo tuần (quy hoạch động, sắp xếp, đệ quy,...).
    *   📁 **`HackerRank/`**: Lời giải các bài trên nền tảng HackerRank.
    *   📁 **`code-thieu-nhi/`**: Các bài luyện tập cơ bản C/C++.
    *   📁 **`personal-project/`**: Mini projects thực hành tư duy thuật toán.
    *   Ngôn ngữ sử dụng chủ yếu: **C/C++**.
    *   Các bài giải tập trung vào phân tích độ phức tạp (Time/Space Complexity) và tối ưu bộ nhớ.

## 🛠️ Môi trường phát triển

*   **Ngôn ngữ:** C, C++
*   **Hệ điều hành:** Ubuntu Linux (chạy qua WSL trên Windows)
*   **Trình biên dịch:** GCC / Clang
*   **Công cụ:** Visual Studio Code Insiders + Git/GitHub + GitHub Copilot

## 🎯 Mục tiêu
*   Nắm vững các thư viện chuẩn (STL) của C++ (Vector, Map, Set,...).
*   Rèn luyện tư duy thuật toán tối ưu, xây dựng nền tảng lập trình vững chắc phục vụ cho định hướng Kỹ thuật Phần cứng và Hệ thống Nhúng.
